# 부품 조사 프롬프트 (2026-11-22)

> 쓰는 법: 자료조사 AI에 아래 코드 블록을 통째로 붙여 넣는다. 첨부 파일은 필요 없다.

```

웹 조사만 한다(구매·장바구니·로그인·판매자 문의 금지). 기준일 2026-11-22. 배송지는 한국.

[로봇 정보 — 사양 판단에 쓰기]
- 모터: Steadywin GIM6010-8 (8:1 유성, 정격 5N·m / 최대 11N·m), 13개
  출력면: 볼록부 Ø34, M3 탭 6개(PCD Ø25, 깊이 5mm), 위치 핀 Ø4 3개(PCD Ø20.4)
- 무릎: 5mm 피치 타이밍 벨트 1.5:1 (모터 쪽 20T → 무릎 쪽 30T), 축간 200mm, 벨트 폭 15mm(20mm 가능)
  벨트 최대 장력 약 690N (20T 피치원 반지름 15.9mm에서 11N·m)
  축 없음. 구동 쪽: 모터 출력판에 연결 부품 → 베어링 6907 1개 → 20T 고정
  무릎 쪽: 6806 – 30T 풀리(구멍 Ø30) – 6806, 두 베어링은 허벅지에 고정
- 제어: Raspberry Pi 5 + Waveshare 2-CH Isolated CAN FD HAT(40핀에 꽂음)
- 전원: 6S LiPo(25.2V 만충), 모터 1개당 최대 약 23A
- 구조물은 처음에 ABS로 출력한다(Bambu Lab P2S). 판금은 나중.
- 다리 4개 분량을 한 번에 산다. 수량 = 필요 + 예비.

[조사 품목]
A. 제어·센서
A1 Pi 5 쿨러 ×1
   - CAN HAT을 위에 꽂은 상태에서 들어가는 높이. 공식 액티브 쿨러가 되면 그것도 포함.
   - 높이가 겹치면 필요한 2×20 스태킹 헤더(긴 핀) 규격과 링크도 같이.
A2 IMU ×1 (예비 포함 2개까지)
   - 9축 또는 6축, Pi 5에서 200Hz 이상으로 읽을 수 있는 것. 3.3V 브레이크아웃 보드.
   - 후보 2~3개 비교: 칩 이름, 연결 방식(UART / SPI / I2C), Pi 5에서 알려진 문제, Linux·Python 라이브러리 유무.
   - BNO085/086은 Pi I2C와 궁합 문제 보고가 있음 → UART-RVC·SPI 가능 여부를 적기.
A3 무선 게임패드 ×1
   - 블루투스로 Pi 5(Raspberry Pi OS / Ubuntu)에 붙고 Linux 입력장치로 인식되는 것.
   - 아날로그 스틱 2개, 버튼 충분. 추천 2개 비교(호환성 근거 링크).

B. 전선·배선 소모품 (실리콘 피복, 고온·유연)
B1 14AWG 실리콘선 적·흑 각 3m 이상
B2 16AWG 실리콘선 적·흑 각 5m 이상
B3 24AWG 실리콘선 노랑·초록 각 5m 이상 (단색 롤)
B4 20AWG 실리콘선 6색 이상 키트, 색마다 2m 이상
B5 편조 슬리브(PET 확장형) 내경 6mm·10mm 각 3~5m + 스파이럴 튜브 6·10mm
B6 링 단자 종합 세트: 12~16AWG(2.5~6mm²)용, 구멍 M4·M5·M6·M8·M10이 섞인 것, 동 주석도금
B7 절연 페룰 0.25mm²(24AWG용) 100개 이상
B8 배터리 고정 스트랩 ×3: 길이 250~400mm, 폭 20mm 안팎, 미끄럼 방지 고무

C. 무릎 벨트·풀리 — AliExpress에서 산다. 풀리와 벨트는 같은 판매처·같은 치형으로
   치형: 5GT(GT5) 우선. 없거나 너무 비싸면 HTD5M. 둘을 섞지 않는다
   폭: 15mm 기본. 같은 판매처에 20mm가 있으면 가격 차이도 적기(벨트 최대 장력 약 690N)
C1 풀리 20T ×5 — 허브 없는 모양 우선(플랜지 양쪽). 구멍 Ø12 안팎, 옆 고정나사 포함 여부
   모터 회전판을 연장한 부품에 끼우고 옆면 나사로 고정할 예정
C2 풀리 30T ×5 — 구멍 Ø30(또는 Ø30으로 넓힐 수 있는 것)
C3 폐루프 벨트 525mm ×6 (축간 200mm, 20T–30T 계산 길이 525.3mm). 525가 없으면 520·530도 적기
C4 같은 치형·폭 벨트의 허용 장력 자료(판매처 또는 Gates 표) → 690N 피크에 충분한지

E1 육각 렌치볼트 M3 12.9 흑색 세트 (6~20mm) — 모터 체결용, 강도 등급 표기 확인
E2 육각 렌치볼트 SUS 세트 M3·M4·M5 (6~30mm)

[기준]
1. 가격을 중요하게 본다. C·D는 AliExpress 우선. 사양이 맞으면 싼 쪽, 평가·판매량이 너무 적은 곳은 제외.
2. 후보: 품목마다 2줄. 추(품질·신뢰 우선) / 최(기준을 통과한 최저가). 같은 상품이면 "추=최" 1줄.
3. 사양이 하나라도 다르면 제외. 비슷한 것만 있으면 체크 칸에 차이를 쓴다.
4. 판매처 제한 없음: 국내(디바이스마트, 엘레파츠, 미스미코리아, 쿠팡, 네이버 스마트스토어 등)와 해외(AliExpress, Amazon, 공식몰). 조건이 같으면 국내 우선.
5. 링크: 상품 상세 페이지 주소만, 직접 열어 본 것만. 검색 결과·광고·단축 URL 금지. 못 찾으면 "없음". 지어내기 금지.
6. 가격: 페이지에 표시된 그대로, 옵션명 그대로. 배송비 따로. 묶음이면 "가격/개수".
7. 도착 예정: 페이지에 표시된 날짜. 없으면 "도착일 불명".
8. STEP/CAD 파일을 받을 수 있으면 체크 칸에 "STEP".
9. 같은 판매처에서 한꺼번에 살 수 있으면 그쪽을 우선 (특히 B, E).
```
