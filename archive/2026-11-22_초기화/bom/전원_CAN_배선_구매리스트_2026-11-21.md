### B. 기술적 확인 사항

1. **메인 퓨즈 40A vs 60A**: 기존 리스트는 60A, 이 리스트는 40A(잠정). 메인선이 12AWG면 40A 쪽이 선 보호에 맞다. 60A를 쓸 거면 메인선을 10AWG로 올려야 한다. 한쪽으로 정리 필요.
2. **정격 없는 주 전원 스위치는 메인 경로에 넣지 말 것**: 40A가 흐르는 직렬 경로에 정격 미표기 부품을 넣으면 접점 발열 위험. 정격 확인 전에는 사지 않고 XT90-S 분리로 대신하는 편이 낫다 (₩2,540 절약).
3. **접촉기 코일 전압 강하**: 점프 피크 때 배터리 전압이 순간적으로 18V 근처까지 처지면 24V 코일 접촉기가 떨어질 수 있다 → 동작 중 모터 전원이 끊겨 넘어짐. 원문 7장 4번(18V 유지 여부)을 **구매 전 최우선**으로 확인. 불확실하면 12V 코일 + 별도 강압, 또는 넓은 코일 전압 범위 제품.
4. **DC-DC**: 이미 Pololu를 사기로 했다면 RCNUN은 예비용으로만. 둘 다 살 이유 없음.
5. 금액 검산: 국내 4곳 합 404,040원, 알리 약 267,000원 + 25A 퓨즈 → 원문 합계(₩673,000)는 맞다.
6. 계산값 검산: 정지 토크 유지 시 배터리 전류 1.5×23.4²×0.22÷24 ≈ 7.5A ✓, 프리차지 25.2V÷20Ω ≈ 1.26A ✓, 1.5KE33A(VRWM 28.2V > 25.2V, 클램프 45.7V < 56V) ✓.

**Inside one XT30(2+2) connector, the pins go to different places:**
- Big pins (+, −): battery power (leg fuse → Y-split).
- Small pins (CANH, CANL): the twisted CAN pair, running back to the CAN HAT.

You solder them together into one connector, but they are two separate circuits.

## 3. Design decisions (with reasons)

**Motor current vs. battery current**
- The spec's rated 10.5A / peak 23.4A is **current inside the motor (phase current)**, not what the battery supplies.
- Battery current = power ÷ battery voltage:
  - Holding a stall: about 7.5A per motor (1.5 × 23.4² × 0.22Ω ÷ 24V, estimate).
  - Brief peaks during a jump can be in the high teens of amps per motor (estimate).
- Neither the C rating nor a seller's "max xx A" claim was used as proof that a part fits.

**Leg fuse (provisional 20A)**
- One fuse per leg in the fuse box, so 4 fuses total. No extra fuse is added on the same leg.
- **Can it protect the thin branch wires?** If the 3 branches to the motors are **16AWG**, a 20A leg fuse protects them, so no per-motor fuse is needed.
  - If you switch to 18AWG, either lower the leg fuse or add a fuse to each branch.
- If the 20A fuse blows during the one-leg test, don't jump to 25A. First log the current, and only move to 25A if the wire rating allows it.

**Main fuse (provisional 40A)**
- It must be larger than the leg fuse (20A) so the leg fuse blows first. It must also be at or below what the 12AWG main wire can carry.
- For four legs, finalize it from the one-leg measurement (peak × 4 legs).
- If that needs more than 40A, change the main wire to 10AWG and use a larger fuse.

**No automatic restart after E-stop release**
- The relay holds itself on only while the start button has been pressed and the circuit is complete.
- Pressing the E-stop cuts the relay coil and lets go of the hold. Releasing the E-stop does nothing until you press start again.
- The Pi branches off before the contactor, so it stays powered even during an E-stop.

**Precharge**
- Hold the precharge button for 1–2 seconds before pressing start.
- With 3 drivers on one leg the inrush is small, so it isn't strictly required. For four legs (12 drivers), use it to reduce wear on the contactor contacts.
- I couldn't find the driver's capacitor size (needs checking).

**Regenerative power**
- Don't assume the battery will always absorb it. The contactor can open while the motors are being back-driven, and a bench power supply can't absorb it at all.
- Steps:
  1. Limit the regen current in the GDS68 settings (the manual's regenerative current setting).
  2. Put the TVS diode on the leg fuse box to catch voltage spikes.
  3. For bench-supply tests, use the brake resistor terminal on the GDS68 (a separate item).

**GND (negative)**
- With a non-isolated step-down converter, the Pi's GND is the same as battery −.
- With an isolated one, the Pi's GND floats separately from battery −.
- Either way, the CAN HAT's isolated-side GND must connect to the battery − busbar **at one point only**.
- Keep these three separate:
  - Motor −: carries large current.
  - CAN reference ground: a single thin wire.
  - Outlet protective earth (PE): only exists on the charger and never connects to the robot.
- **Separate distribution blocks aren't needed.** The fuse box's − busbar does the − distribution, and the contactor input terminal does the + split. The Y-split inside each leg is a solder joint with adhesive heat-shrink.

**Pi 5 power**
- The Pi 5's standard is a 5.1V 5A USB-C PD supply.
- A plain 5V supply that doesn't negotiate PD can't tell the Pi it supplies 5A. If you plug in a lot of USB devices, add `usb_max_current_enable=1` to the Pi's config.txt file.
- The DC-DC output is 5.0V, so check for undervoltage warnings.

**CAN layout**
- A signal hub isn't needed. The three motors on each leg are close to the hip, so each channel can use one trunk line along the body plus short stubs of 30cm or less.
- Termination: the HAT end uses its jumper, and the far end uses a 120Ω resistor.
- Before adding a resistor, check with the power off: if the multimeter reads about 60Ω between H and L, the drivers already have termination built in, so don't add another.

## 7. Check before placing the final order

1. **Battery:** dimensions and the gender of its XT90 connector. The robot side and the charge adapter must be the opposite gender. The 926g weight is also over the 714g baseline.
2. **Charger:** the gender of the M7AC's XT60 output port, and whether an AC cord is included.
3. **XT30(2+2) pins:** which small pin is CANH and which is CANL. Check the manual's interface diagram or with a multimeter. Getting the big +/− pins backwards will burn the driver, since it has no reverse-polarity protection.
4. **Contactor:** coil current, whether it stays engaged at 18V, terminal bolt size (to decide on M8 ring terminals), and whether a diode is built in.
5. **Fuse box and main switch:** check total/per-circuit current ratings and the internal layout (one common + stud and a − bus) in the description images.
6. **DC-DC:** continuous output and output voltage. If unclear, switch to the Pololu.
7. **USB-C cable:** whether it handles 5A. If not, go to the 40-pin header option.
8. **GDS68:** whether it has built-in termination (check for 60Ω) and the regen current limit setting value.
9. **Fuse values:** after the one-leg test, log the current and finalize the leg fuse (20/25A) and the main fuse (40A/larger).
10. **Prices:** check the selected-option prices for the 25A fuse, 12-24V start button, 22MM E-stop, and OT4-6/OT2.5-5 ring terminals.
11. **120Ω resistor:** I couldn't find a listing.
