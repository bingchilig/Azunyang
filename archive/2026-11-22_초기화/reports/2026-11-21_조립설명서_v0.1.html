1. 원리: 로봇이 움직이는 방법

1-1. 전기와 신호가 흐르는 길

그림 1. 시스템 구성 (비율 아님)
  • Pi 5가 두뇌입니다. IMU로 몸 기울기를 읽고, 다리마다 "이 각도로, 이만큼 단단하게" 명령을 계산해 CAN으로 모터 12개에 초당 250번 보냅니다.
  • 모터(GIM6010-8) 안에는 드라이버(GDS68)가 들어 있어서, 명령을 받으면 스스로 전류를 조절해 토크를 내고 현재 각도·속도·토크를 돌려보냅니다.
  • CAN은 전선 2가닥(CANH·CANL)에 장치 여러 개가 줄줄이 매달린 통신선입니다. 모터마다 ID(1~12)가 있어서 자기 ID로 온 메시지만 듣습니다. 버스 양 끝에만 120Ω 종단저항을 켜서 신호가 끝에서 튕겨 돌아오지 않게 합니다.
  • 앞다리 6개(ID 1~6)는 can0, 뒷다리 6개(ID 7~12)는 can1에 연결합니다. 한 버스에 12개를 다 달면 통신량이 너무 많기 때문입니다(1Mbps, 250Hz에서 버스 사용률 37.5%).

1-2. 다리 하나 = 관절 3개 = 모터 3개

관절움직임모터 위치힘이 전달되는 길CAN ID (FL 기준)
외전 (abad)다리를 옆으로 벌림몸통모터 출력 → 외전 링크(U프레임) 직결1
고관절 (hip)다리를 앞뒤로 휘두름외전 링크모터 출력 → 상퇴(허벅지) 직결2
무릎 (knee)하퇴를 접고 폄외전 링크 (고관절과 같은 축)모터 → 구동축 → 20T 풀리 → 벨트 → 30T 풀리 → 하퇴3
왜 무릎 모터를 무릎이 아니라 고관절 옆에 두나? 다리 끝이 가벼워야 빨리 휘두를 수 있습니다. 무거운 모터(388g)를 몸 가까이 두고 무릎에는 벨트로 힘만 보냅니다. MIT Mini Cheetah와 같은 원리입니다.
왜 20T → 30T? 풀리 지름 비 1.5배만큼 무릎 토크가 1.5배 커집니다(속도는 1/1.5). 서 있을 때 무릎이 몸무게를 가장 많이 받기 때문입니다.
모터 자체도 8:1 감속. 정격 5N·m, 최대 약 11N·m. DE(2차 엔코더)는 감속기 뒤 출력축 각도를 직접 읽으므로 전원을 켜자마자 다리 각도를 알 수 있습니다(기준점 잡기 불필요).

1-3. 고관절 스택: 몸 옆 방향(y)으로 쌓이는 순서

그림 2. 고관절 스택 단면 개념도 (보고서 배치 기준, 치수 mm, 비율 근사)

2-2. 안전 규칙

LiPo 배터리: 충전은 반드시 LiPo 가방 안에서, 사람이 보는 동안만. 부풀거나 뜨거워지면 즉시 사용 중지. 셀당 3.5V 아래로 쓰지 말 것(셀 체커(53)가 경고).
전원 작업: 배선을 만지기 전에 E-stop을 누르고 XT90-S를 뽑는다. 벤치 전원은 처음 켤 때 전류 제한을 2A로 낮게.
모터: 11N·m는 손가락을 다칠 수 있는 힘. 관절 사이에 손을 넣은 채 명령을 보내지 않는다. 처음 움직일 때는 토크 제한을 낮게.
회생 전기: 모터를 빨리 돌리다 멈추면 전기가 거꾸로 흐른다. 벤치 전원만 쓸 때는 브레이크 저항 또는 드라이버의 역전류 제한(dc_max_negative_current) 설정.

3. 1단계: 모터 1개 책상 시험

목표: 모터 12개를 다 사기 전에, 2개로 토크·열·백래시·DE가 사양대로인지 확인한다. 결과가 나쁘면 설계를 바꿔야 하므로 가장 먼저 하는 단계.

필요한 부품: 모터 (56) ×2, USB-CAN (10), 벤치 전원 (67), XT30(2+2) 연장 케이블 (66), 바나나 플러그 (11), 벤치용 퓨즈 홀더 (12), 16AWG (48), 24AWG 키트 (17), 로드셀+HX711 (68), 아두이노 (13), 분동 (73), 아이볼트·와이어 (61), 다이얼 게이지 (72), 멀티미터 (14), M3×8·M3×10 12.9 볼트 (35·36), Loctite (78), PETG (71), 열수축 (24)

3-1. 준비물 만들기

1. 모터 고정 지그: PETG(71) 블록 또는 알루미늄 판에 모터 뒷면 구멍(PCD 74mm, 8개, Ø3.4)과 중앙 Ø62 구멍을 낸다. 모터를 M3×8 12.9 볼트(35) 8개 + Loctite(78)로 1.2N·m 고정하고, C클램프로 책상에 고정한다.
2. 전원 케이블: 벤치 전원(67) + 단자 → 바나나 플러그(11) → 16AWG 적(48) → ATO 퓨즈 홀더(12) → XT30(2+2) 케이블(66)의 + 핀. − 쪽은 흑선으로 바로. 납땜부는 열수축(24).
3. CAN 선: XT30(2+2) 신호 핀 2개(CANH·CANL)를 24AWG 노랑·초록(17)으로 USB-CAN(10) 단자에. USB-CAN의 120Ω 스위치 ON.
4. 확인: 전원 끈 상태에서 멀티미터(14)로 CANH–CANL 저항을 잰다. 약 60Ω이면 정상 (USB-CAN 120Ω과 모터 120Ω이 병렬). 120Ω이면 한쪽 종단이 꺼진 것.

3-2. 첫 전원과 설정

5. 벤치 전원을 24.0V, 전류 제한 2A로 맞추고 출력 ON. 전류가 수백 mA 안에서 안정되는지 본다.
6. PC에 USB-CAN 연결 → odrivetool 또는 python-can으로 통신. 모터 ID 설정(첫 모터 1), CAN 속도 500k → 1M, 엔코더 보정. 두 번째 모터도 같은 방법(ID 2).
7. 손으로 출력축을 돌리며 각도 값이 따라 바뀌는지 확인. 전원을 껐다 켜도 같은 각도가 나오면 DE 정상.

3-3. 측정

8. 로드셀 교정: 로드셀(68) → HX711 → 아두이노(13) → PC. 분동 2kg(73)을 달아 값 = 19.6N이 되도록 계수를 맞춘다.
9. 토크 시험: 출력 플랜지에 토크 암(알루미늄 3×20×250, 구멍 중심 200.0mm)을 M3×10 12.9(36) 6개로 체결. 암 끝 → 아이볼트·와이어(61) → 로드셀 → 고정점. 전류 제한을 단계적으로 올리며 명령 토크 증가. 토크 = 힘 × 0.2m. 목표: 24A에서 약 11N·m.
10. 열 시험: 5N·m를 20~30분 유지. K형 열전대를 모터 하우징에 캡톤 테이프로 붙이고 멀티미터(14)로 1분마다 기록.
11. 백래시: 출력을 위치 명령으로 붙잡은 상태에서, 토크 암의 반경 50mm 지점에 다이얼 게이지(72)를 대고 손으로 좌우로 민다. 사양 15arcmin = 약 0.22mm (50 × tan 0.25°).

최대 토크 (24A)≥ 10N·m
5N·m 30분 후 온도기록
백래시 (r = 50mm)≤ 0.22mm

결과 판단: 모두 OK면 나머지 모터 구매 확정. 토크·열이 부족하면 HANDOFF 6장의 대안(목표 7kg / 무릎 2:1 / 무릎만 GIM8108-8) 중 선택.

4. 2단계: 다리 1개 조립과 시험대

목표: 다리 1개(FL)를 실제로 조립해 치수·벨트·강도·배선을 확인하고, Pi 5로 스쿼트·낙하 시험을 한다. 여기서 찾은 문제를 고친 뒤 나머지 3개 다리와 몸통을 만든다.

4-1. 다리 시험대 (지그)

1. 2020 프로파일(79) 500mm ×4로 기둥·바닥, 300mm ×4로 가로대. 코너 브래킷·T너트·M5 볼트로 사각 탑 조립.
2. 한쪽 기둥에 MGN12 레일 400mm, 캐리지에 캐리지판(외전 마운트와 같은 PCD 74 구멍). 캐리지판이 "몸통" 역할 → 위아래로만 미끄러진다.
3. 바닥에 EVA 폼 20mm (낙하 완충) + 레일 하한 스토퍼.
레일·브래킷·EVA 폼·캐리지판은 아직 구매처 미정(보류 목록). 지그 CAD도 없음 → 실물 맞춤.

4-2. 외전 관절

4. 캐리지판에 외전 모터(ID 1) 뒷면을 M3×8 12.9(35) 8개 + 와셔(42) + Loctite(78), 1.2N·m.
5. 외전 모터 출력에 외전 스페이서 + 외전 U프레임(알루미늄 2mm 판금)을 M3×10 12.9(36) 6개. 출력면 Ø4 핀 3개가 구멍에 들어가는지 먼저 확인. → U프레임이 외전 축을 중심으로 좌우로 흔들린다.

4-3. 고관절 스택 (그림 2의 순서)

6. 고관절 모터(ID 2) 뒷면 → U프레임의 고관절 장착판, M3×8 12.9 ×8.
7. 무릎 모터(ID 3) 뒷면 → 무릎 장착판, M3×8 12.9 ×8. 두 모터가 같은 축(고관절 축)에 마주 보고 놓인다.
8. 고정 스핀들 Ø30(중공)을 스핀들 플랜지로 U프레임(무릎 모터 쪽)에 M3 볼트(38) + 나일론 너트(59). 이 스핀들은 돌지 않는다.
9. 스핀들 안에 6801ZZ(64) 2개를 넣고 Ø12 구동축(미스미 홈 가공 축)을 통과. 한쪽 끝 = 무릎 모터 출력과 허브로 연결(M3×10 12.9 ×6), 다른 끝 = 20T 풀리(27), 무두볼트로 D컷 면 고정. 양끝 홈에 스냅링 Ø12(33).
무릎 모터 출력 ↔ 구동축 연결 허브의 형상은 CAD에서 아직 확정 안 됨. 조립 전 Fusion에서 단면 확인 필요.

4-4. 상퇴 (허벅지)

10. 상퇴 안판(1.5mm)을 고관절 모터 출력에 출력 스페이서와 함께 M3×10 12.9 ×6. → 상퇴가 고관절 모터와 함께 돈다.
11. 상퇴 바깥판 구멍에 6806ZZ(62)를 넣고 리테이너 내·외로 누른다(M3×10 SUS(39) + 나일론 너트(59)). 이 베어링을 스핀들에 끼운다. (리테이너가 내륜을 잡지 못하면 스냅링 Ø30(34) 사용)
이제 상퇴는 한쪽 = 고관절 모터 출력, 다른 쪽 = 6806 베어링으로 양쪽 지지된다. 무릎 모터의 구동축은 6806 안쪽의 스핀들을 관통하므로, 상퇴가 돌아도 구동축은 따로 돈다.
12. 안판·바깥판 사이를 횡연결판 상·하로 묶는다(M3×8 SUS(38) + 와셔 + 나일론 너트). → 두 판이 상자처럼 묶여 비틀림에 강해진다.

4-5. 하퇴와 무릎

13. 하퇴 출력: PETG(71), 벽 3mm 중공, 표면층 1.2mm, 코어 30~40% 인필, 길이 방향을 출력판(XY)에 눕혀서. 끝단·풀리 자리·베어링 리테이너 자리에 M3 인서트(3) 압입.

17. 백아이들러 Ø45(30)를 상퇴의 장공 지지판 내·외 사이에 Ø10 숄더볼트 + M8 나일론 너트로 건다. 아이들러를 벨트 바깥면에 대고 장공을 따라 밀어 팽팽하게 한 뒤 M3×12(37) + 너트로 장공 고정.
벨트 장력 원리: 두 풀리만으로 계산한 경로는 525.3mm인데 벨트는 530mm(가장 가까운 표준 길이)라 4.7mm가 남는다. 아이들러가 벨트를 바깥에서 눌러 이 여유를 흡수한다. 너무 세게 당기면 베어링 부담, 너무 느슨하면 이가 튄다 → 손가락으로 벨트 중간을 눌러 5mm 정도 들어가는 정도에서 시작해 시험으로 조정.
아이들러 핀이 Ø5 → Ø10으로 바뀜(미스미 아이들러 보어 Ø10). CAD의 핀 구멍·장공 폭 수정 필요. 아이들러는 15mm 벨트용 폭 형번으로 주문.

5. 3단계: 로봇 전체 조립

5-1. 몸통

1. 섀시(알루미늄 3mm)에 외전 마운트 4개를 M4×12(41) + 와셔(43) + 나일론 너트(60), 1.8N·m. 앞뒤 고관절 간격 380mm, 마운트 면 |x| = 140mm.
2. 섀시 아래층에 배터리 레지 ×4·서포트 ×4(PETG) → 배터리 트레이. 트레이 래치 ×2는 인서트 + M3×10.
3. 섀시 접근 덮개 자리에 M4 리벳너트(44) 4개.
리벳너트는 지금 고른 형번이 판 두께 1.5~2.5mm용 → 3mm용 형번으로 다시 주문.

5-2. 다리 4개

4. 2단계와 같은 순서로 FR·RL·RR 조립. 오른쪽 다리는 거울상, 무릎은 4개 모두 뒤로 꺾임(>>).
5. 각 다리 외전 모터를 외전 마운트에 M3×8 12.9 ×8 + Loctite, 1.2N·m.

5-3. 전원 회로 (전장 선반)

그림 4. 전원 회로 (비율 아님)
6. 전장 선반 2개를 섀시에. 선반에 접촉기(69)(M4), MIDI 퓨즈 홀더(80)(M4), 버스바 +/−(M3), DC-DC(8).
7. 주 전원 (12AWG(46)): XT90-S + → 접촉기 A / 접촉기 B → MIDI 퓨즈 → 버스바 + / XT90-S − → 버스바 −. 선 끝 링 단자(20) 압착 + 접착 열수축(25).
8. E-stop 코일 회로 (20AWG(16·50)): 접촉기 A → 2A 퓨즈 → JST-SM(19) → 커버의 E-stop(6) NC 접점 → JST-SM → 접촉기 코일 + → 코일 − → 버스바 −. 코일 양끝에 다이오드(5): 띠(캐소드)가 + 쪽.
E-stop 원리: 접촉기는 코일에 전기가 들어가 있는 동안만 붙어 있는 큰 스위치입니다. E-stop을 누르면 코일 전기가 끊겨 접촉기가 떨어지고 모터 전원이 차단됩니다. 다이오드는 코일이 끊길 때 생기는 역전압 불꽃이 E-stop 접점을 태우지 않게 흡수합니다.
9. 프리차지: 접촉기 A → 47Ω 25W 저항 → 프리차지 버튼(7) → 접촉기 B (20AWG). 저항은 방열을 위해 섀시에 볼트로.
프리차지 원리: 모터 드라이버 12개 안의 콘덴서가 비어 있을 때 접촉기를 바로 붙이면 순간 큰 전류가 흘러 접점이 녹아붙을 수 있습니다. 버튼을 2~3초 눌러 저항을 통해 천천히 미리 채워 둡니다.
10. TVS 다이오드를 버스바 +/− 사이에 리드를 짧게(30mm 이하). 접촉기가 떨어질 때 생기는 순간 과전압을 흡수.
11. 다리 분기: 버스바 → ATO 퓨즈 홀더(9) + 25A → 14AWG(47) 220mm → 몸통 쪽 XT60 암(51). 다리 4개 모두.
12. 5V: 버스바 → 3A 퓨즈 → 18AWG(49) → DC-DC 입력. DC-DC 출력 → USB-C 케이블(22) → Pi 5. Pi의 config.txt에 usb_max_current_enable=1.
버스바, 47Ω 저항, TVS, 25A/2A/3A 퓨즈, 미니 블레이드 홀더는 아직 구매처 미정(보류 목록).

5-4. 제어부와 CAN

13. 다른 선반에 Pi 5 + 쿨러 + HAT 묶음(스페이서(4)), IMU(74)를 몸 중심 가까이 스페이서로.
14. IMU → Pi GPIO 점퍼선(23): 3.3V, GND, TX, RX (UART 방식 권장. Pi에서 I2C는 이 센서와 궁합 문제 보고가 있음).
그림 5. CAN 버스 2개. 끝 모터(ID 6, 12)만 120Ω ON, 나머지 10개는 OFF
15. can0: HAT → FL 외전 → FL 고관절 → FL 무릎 → FR 외전 → FR 고관절 → FR 무릎(끝). can1: RL → RR 같은 방식. ID 1~6 앞, 7~12 뒤.

5-5. 배터리와 덮개

18. 배터리(52)를 충전기(70)로 LiPo 가방 안에서 충전. 셀 체커(53)를 밸런스 단자에.
19. 배터리를 트레이에 넣고 스트랩(54)으로 고정. 래치 걸기.
배터리(DOGCOM 5500mAh, 926g)가 트레이 180×80mm에 들어가는지 받자마자 치수 확인. 무게가 예산보다 약 200g 많음.
20. 커버: 윗면에 E-stop(22mm 구멍)·프리차지 버튼. JST-SM 커넥터를 꽂고 커버를 M4×12로 닫는다.
21. 배터리 접근 덮개를 널링 손나사(45)로 닫는다.

6. 처음 켜기와 끄기

처음 켤 때는 로봇을 배를 위로 뒤집어 받침대에 올려 다리가 허공에 뜬 상태로. 주변에 손·물건이 없게.
1. E-stop이 눌려 있는지 확인.
2. 배터리 XT90-S 연결 (안티스파크라 불꽃 없음). 이때 Pi는 아직 꺼져 있다(DC-DC가 접촉기 뒤에 있으므로).
3. 프리차지 버튼을 2~3초 누른다.
4. 누른 채로 E-stop을 돌려 푼다 → 접촉기 "딸깍" → 모터 12개와 Pi에 전원.
5. Pi 부팅 → 모터 12개 응답 확인 → 관절 하나씩 작게 움직이기.
6. 바닥에 놓고 일어서기 → 제자리 걸음 → 걷기 → 트롯(250Hz) 순서.
7. 끌 때: E-stop 누름 → 배터리 XT90-S 분리 → 배터리는 LiPo 가방에 보관.
