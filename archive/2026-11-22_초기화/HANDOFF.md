## 0. 30초 요약

- **무엇:** MIT Mini Cheetah를 참고한 12자유도 사족보행 로봇개 "Azunyang". 목표 무게 약 8kg, 크기 약 50×33×34cm(비글·코기 정도).
- **확정:** 액추에이터는 **SteadyWin GIM6010-8 + GDS68 드라이버 + DE(출력축 2차 엔코더)**, 3D 모델은 **Standard Version** STEP.
- **추천 설계안:** 무릎 모터를 고관절 동축에 두고 **HTD5M 20T→30T(1.5:1) 벨트**로 무릎 구동. 고관절·외전은 직결.
- **현재 단계:** 리서치 끝 → **Fusion 모델링 시작 직전**. GPT에게 모델링을 시킬 예정이고, 지침은 `MODELING_PROMPT.md` + `GPT_FUSION_PROMPT.md`.
- **아직 아무것도 사지 않았음.** 1단계 구매(모터 2개 + 시험 장비)가 다음 실물 작업.

## 1. 사용자와 작업 방식

- 사용자는 한국어로 소통하고, 한국에 거주. Fusion으로 모델링, FDM 프린터(PLA/PETG), 납땜 가능, **CNC 없음**, FOC·CAN은 처음.
- 포트폴리오·발표용으로 **과정 기록을 중요하게 여김** → 결정·실험·실패는 Obsidian에 남긴다.
- 역할 분담:
  - **aside(별도 에이전트):** 웹 자료조사. 사용자가 프롬프트를 붙여 넣어 실행하고, 결과를 이 대화에 붙여 넣음.
  - **Claude(이 세션):** 프롬프트 엔지니어링, Obsidian 기록, 정리·검토.
  - **GPT:** Fusion 모델링 담당 예정 (`GPT_FUSION_PROMPT.md` 참고).
- 규칙: 수치에는 출처·계산·"추정" 표시. 구매·주문·판매자 연락은 사용자 확인 없이 하지 않음.

## 3. 핵심 사양과 수치

### 3.1 액추에이터 GIM6010-8 (24V, GDS68) — 제조사 사양표 `actuator/GIM6010-8/Parameters of GIM6010-8.pdf`
| 항목 | 값 |
|---|---|
| 감속 | 8:1 스틸 유성, 백래시 15arcmin |
| 정격 / 피크 토크 | 5.0 / 11.0 N·m |
| 정격 / 피크 전류 | 10.5 / 23.4 A, 토크상수 0.47 N·m/A |
| 속도 | 정격 120rpm, 최대 420rpm (출력축) |
| 무게 / 크기 | 388g (드라이버 포함) / Ø80×40mm |
| 허용 하중 | 축 200N, 반경 800N (모멘트 허용치 확인 불가 → 상퇴 양쪽 지지 필수) |
| 통신 | CAN (기본 500k → **1M으로 변경 필요**), MIT 모드 지원 |
| 엔코더 | 사양표 16bit, 매뉴얼 rev2.2·사용자 설정값은 14bit → **판매자 확인 필요** |

출력 플랜지(Standard 도면): Ø20.4±0.05 보스, Ø25±0.10, 6-M3 깊이5, 3-Ø4±0.05 핀, Ø74±0.10 원주 8-M3 깊이5. 뒷면 Ø74 원주 8-M3 깊이5, 드라이버부 Ø57. **PCD 일부는 도면에 없음 → STEP에서 실측.**

### 3.3 제어·전원
- Raspberry Pi 5 + Waveshare 2-CH CAN FD HAT(MCP2518FD). 버스 2개×6축, 250Hz부터. (MCP2515 HAT은 비추천)
- 소프트웨어 출발점: MBF 프로젝트(GIM6010-8 ×12, ROS2 + CHAMP) https://github.com/adwng/mbf_ros2
- 시뮬레이션: Fusion → ACDC4Robot → MuJoCo
- 전원: 6S LiPo 5000mAh → XT90-S → E-stop + DC 접촉기 → 60A MIDI 퓨즈 → 다리별 XT30 → 24V→5V DC-DC. 사용 시간 약 35~50분(추정).
- CAN ID: FL 1·2·3, FR 4·5·6 (can0) / RL 7·8·9, RR 10·11·12 (can1)

### 3.4 예산·구매 (2026-11-12, 1달러=1,340원)
- 1단계 약 65만(모터 2개 + 시험 장비) → 2단계 약 72만(다리 1개, Pi, 배터리) → 3단계 약 244만(나머지)
