## 다음 작업 계획 — 아직 미승인/미실행

현재 y_hipmot=65 mm, y_kneemot=139 mm를 유지한 FL 기준 배치를 먼저 제안한다. 좌표는 base_link 기준이며 아래 값은 계산한 목표값이다. 실제 배치 후 측정값이 아니다.
y_hipmot/y_kneemot은 각 모터의 핀·커버 포함 y 외곽 중 작은 쪽 경계로 정의하는 계획이다. abad_x는 전체 축방향 외곽의 중앙으로 해석한다.

| 대상/작업 | 매개변수 | 예상 결과 | 되돌리기 |
|---|---|---|---|
| ACT_ref를 공유하는 FL 외전 occurrence | abad_x, abad_y, act_L, act_mount_L, pin_H | 출력면(143.5, 45, 0) mm, 출력방향 +X | 해당 배치 MCP 작업 Undo |
| ACT_ref를 공유하는 FL 고관절 occurrence | hip_spacing,y_hipmot,act_mount_L,act_L | 출력면(190, 105.5, 0) mm, 출력방향 +Y; y=65~109 mm | 해당 배치 MCP 작업 Undo |
| ACT_ref를 공유하는 FL 무릎 occurrence | hip_spacing,y_kneemot,pin_H,act_L | 출력면(190, 142.5, 0) mm, 출력방향 -Y; y=139~183 mm | 해당 배치 MCP 작업 Undo |
| 참조 occurrence 표시 끄기 | 없음 | 기준 ACT_ref:1만 숨김; 작업3개 표시 유지 | 참조 occurrence 표시 켜기 |
| 재조회/간섭 분석 | 현재 매개변수 읽기 | 배치 행렬, 출력면 중심, 물리 축, 전체 외곽, 모터 간 간섭쌍/체적 | 읽기 전용, 되돌리기 불필요 |

Occurrence.name은 읽기 전용이며 component명을 공유한다. 실제 브라우저명 ACT_ref:n을 그대로 두고 FL_abad_motor/FL_hip_motor/FL_knee_motor 역할을 occurrence attribute로 구별할 계획이다. 최종 링크/관절 이름은 §1.2를 따르며 이 작업에서 조인트는 만들지 않는다.
모터의 물리 출력방향과 논리 joint +Y축은 구분한다. 무릎 출력이 -Y여도 향후 joint축/부호는 별도 검증한다.
참조 ACT_ref:1은 간섭 대상에서 명시적으로 제외한다. 모터 내부 자체 중첩과 서로 다른 모터 사이 간섭도 구분해 보고한다.

## 계산과 변경 선택지

- [계산] 현재 전체 모터 폭 W=2(y_kneemot+act_L)=2(139+44)=366 mm. 358 mm 목표 초과8 mm.
- [계산] 358 mm를 맞추는 단순 위치 후보 y_kneemot=358/2-act_L=135 mm. 출력면 y=135+pin_H=138.5 mm.
- 이 후보는 기존 베어링 영역132~139 mm와 축방향 영역이 겹치므로 공간/지지 검증 전 바로 적용하지 않는다. 실제 간섭 여부는 형상 모델이 없어서 HOLD다.
- 추천: 현재139 mm에서 FL 모터3개 기준 배치·실측을 먼저 수행하고, 358 mm는 목표로 유지한 채 지지 구조와 함께 위치 변경안을 제시한다. 366 mm를 새 확정 폭으로 승인하는 뜻이 아니다.
- 벨트 실제 폭 후보는 leg_y±belt_w/2=110~130 mm, 기존 y_belt108 mm는 여유 포함 영역 시작으로 해석하는 계획이다. 풀리/플랜지/안판은 미작성이라 여유 PASS 판정 불가.
