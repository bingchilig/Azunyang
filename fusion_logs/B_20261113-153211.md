## 8. MCP 응답 문제 및 대응

- 처음 두 API 문서 조회는 필수 searchPattern 누락으로 “Missing required field: 'searchPattern'” 응답. 필드를 보완한 읽기 재조회로 정상 문서 확인 후 모델 작업을 시작했다.
- RR hip 생성 후 readOnly 측정 응답에 “[output truncated: exceeded 1 MiB]”가 반환돼 외부 JSON 파싱이 실패했다. 이후 짧은 print도 빈 응답이었다. 원인은 MCP 출력 수집 한도로 추정되며 서버 내부 원인은 확인 불가다.
- 이때 모델 변형을 멈추고 동일 readOnly MCP 기하 조회 결과를 fusion_logs 파일로 직접 기록하도록 출력 경로만 바꿨다. 해당 파일을 읽어 11개 모터 상태를 검증한 뒤 마지막 RR knee를 생성했다.
- 모델 측정 FAIL은 없었다. stdout 빈 응답을 성공 측정으로 간주하지 않고 파일에 실제 기록된 값으로만 판정했다. 최종 원문 JSON에 기준·생성 과정·각 시험·위상·최종값을 보존했다.
- 원시 기록: B_20261113-153211_measurements.json. 임시 B9_* JSON 및 B_20261113_9motor_live.jsonl도 이 폴더에 있다.
