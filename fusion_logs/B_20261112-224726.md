## 사용자 질문 ② — act_L 측정 기준

- 기준 ACT_ref 축방향 +X, 핀과 드라이버 커버를 포함한 전체 외곽.
- 이번 읽기에서 커버 끝 X=-11 mm, 핀 끝 X=+33 mm를 재확인.
- 전체길이=33-(-11)=44 mm [측정 외곽으로 계산].
- 출력 장착면 X=29.5 mm는 이전 B-1 면 측정 및 이번 배치 형상 대응 face index589.
- 커버 끝→출력 장착면40.5 mm + 출력면→핀 끝3.5 mm =44 mm.
- 이는 사양서 명목40 mm와 측정 범위/버전이 동일하다고 확인한 값이 아니다. 제조사/실물 확인 HOLD 유지.

## 실제 생성 및 배치 방법

- ACT_ref:2 = FL_abad_motor, ACT_ref:3 = FL_hip_motor, ACT_ref:4 = FL_knee_motor.
- 역할은 occurrence의 Azunyang/role attribute에 저장했다. 세 occurrence.component가 모두 원본 ACT_ref.component와 같은지 API로 확인했다.
- 내부 STEP 어셈블리 계층 보존. 각 모터 솔리드2개, 루트 occurrences5개(base_link,참조1,작업3).
- 기준 ACT_ref:1만 isLightBulbOn=false. 작업3개는 true.
- 위치는 User Parameters의 식을 UnitsManager.evaluateExpression으로 평가하고, 참조 STEP의 실제 축방향 외곽과 결합해 생성했다.
- xyz숫자를 cm로 직접 하드코딩하지 않았다. 0 mm도 단위식 평가. 회전행렬 방향벡터는 무차원.
- 현재 occurrence 변환은 실행 시 매개변수를 평가한 위치다. 조인트/구속식으로 자동 연동된 배치는 아직 아니다. 매개변수 변경 시 역할별 재배치 호출 후 다시 측정해야 한다.
- 역할 중복 검사 후 기존 occurrence 갱신 또는 신규 생성하는 멱등 절차.
- 물리 출력축 방향과 향후 논리 관절축 +Y는 구별한다. 조인트는 이번에 만들지 않았다.

## 독립 MCP 측정 — 배치된 실제 형상

출력 평면(face589)과 Ø34 원통면(face587)을 occurrence 문맥에서 읽었다. 원통 중심축과 출력 평면의 교점을 출력면 중심으로 사용했다. 면 법선은 Face.evaluator로 측정했다. 참고 면 번호는 이번 STEP에만 해당한다.

- 세 모터 Ø34 보스 원통 지름을 각각34 mm로 재조회. 기존 스케치3개 완전 구속, health0, 경고 없음.
- 계획 좌표 대비 오차는 표시 정밀도0.001 mm 이내. 10배 단위 오류 없음.

## 간섭과 최소 간격 — 현재 FL 정적 배치에 한정

Design.createInterferenceInput/analyzeInterference를 사용했다. 서로 다른 모터의 솔리드 바디 조합을 쌍별4개, 총12개 검사했다. 기준 ACT_ref:1과 같은 모터 내부 자체 조합은 명시적으로 제외했다. areCoincidentFacesIncluded=false. 간섭 결과 body는 생성하지 않았다.
최소 간격은 MeasureManager.measureMinimumDistance로 각 바디 조합을 측정한 최소값이다.

| 모터 쌍 | 검사 바디 쌍 | 간섭 수 | 총 간섭체적 mm³ | 최소 간격 mm |
|---|---|---|---|---|
| FL_abad_motor / FL_hip_motor | 4 | 0 | 0 (간섭 결과 없음) | 10 |
| FL_abad_motor / FL_knee_motor | 4 | 0 | 0 (간섭 결과 없음) | 62.132675 |
| FL_hip_motor / FL_knee_motor | 4 | 0 | 0 (간섭 결과 없음) | 30.683473 |

현재 3개 모터간 정적 간섭 검사 PASS. 몸통/브래킷/풀리/베어링/케이블 미작성이고 관절도 없으므로 전체조립체 또는6개자세 간섭 PASS로 확대하지 않는다.

## 계산 / 폭 HOLD

- 실측 FL 무릎 모터 바깥쪽 y=183 mm.
- 같은 위치를 좌우 대칭으로 적용할 경우 예상 모터폭=2×183=366 mm [계산]. 오른쪽은 아직 배치하지 않았으므로 전체폭을 실측했다고 하지 않는다.
