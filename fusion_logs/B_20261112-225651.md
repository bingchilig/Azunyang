## 원인 추정과 수정 계획 — 미실행, 승인 필요

관찰: 상위 ACT_ref의 jointOrigins.add를 호출했어도 참조 면의 소유자인 하위 본체에 원점이 생성됨.
추정: Fusion이 면 기반 JointGeometry의 소유 컴포넌트로 생성 위치를 정한 것으로 보임. 이 방식으로는 목표한 상위 어셈블리 전체의 원점 소속을 보장하지 못했다.
위험: 이 원점으로 바로 조인트를 만들면 전체 모터보다 하위 본체가 구속될 수 있으므로 진행하지 않았다. 실제 부품이 이동한 것은 아니다.

수정 제안:
1. 마지막 모델 변경이 그대로인지 확인 후 이번 원점 생성 작업만 Undo. 사용자 또는 다른 작업의 이후 변경이 있으면 무조건 Undo하지 않음.
2. 추가 User Parameter act_ref_output_x=29.5 mm 승인 요청. [실측] 기준 STEP 좌표계에서 출력 장착면 중심의 X 좌표. 전체길이/물리치수 변경이 아닌 참조 좌표이다.
3. ACT_ref 자신의 originConstructionPoint로 JointGeometry를 만들고 offsetX=act_ref_output_x, offsetY=0 mm, offsetZ=0 mm인 원점을 생성.
4. 원점 실제 parentComponent가 ACT_ref인지 먼저 검사하고 실제 출력면 중심과≤0.001 mm 일치 여부 검사. STEP 교체 시 재측정해야 함.
5. 위 준비 검증이 통과한 뒤 승인된 base_link 고정/FL 목표원점/Rigid Joint 생성 및3개 파라미터 시험을 재개. FAIL이면 동일하게 즉시 중지하고 Undo 전 보고.

추가 매개변수 표

| 이름 | 값 | 단위 | 근거 |
|---|---|---|---|
| act_ref_output_x | 29.5 | mm | [MCP 실측] ACT_ref 로컬 좌표에서 출력면 중심 X |

이번 승인에는 신규 User Parameter 추가가 포함되지 않았으므로 적용하지 않았다.
도면/STEP 차이, 전체폭366예상/358목표, 지지 적층 등 기존HOLD는 유지.
