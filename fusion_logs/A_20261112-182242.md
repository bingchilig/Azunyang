- 각 자세의 선분은 상퇴·하퇴, 고관절 위치 구성선, 높이 구성선, 지면 구성선이다.
- 지면 표시 구성선의 길이는 L_thigh로 연결했다. 이는 스케치 표시 범위다.
- 참고 파일 수정 없음.

## MCP 실행 결과와 복구

1. 시작 상태 조회 성공. parameters=[], components=[], root_sketches=[], isModified=false.
2. 원래 Ts 등록 시 실패. 오류 원문은 아래와 같다.

```text
RuntimeError: 3 : param name is not valid
```

실패 직후 다시 읽은 User Parameters 목록은 []였다.
원인 확인용 읽기에서 1 Ts는 1000000000000 s, 1 Tl은 1000000000000000 cm^3로 평가됐다.
Fusion의 단위명 충돌로 판단하고 사용자에게 이름 변경 승인을 받은 뒤 재등록했다.

3. Ts_teeth/Tl_teeth를 사용한 36개 등록 성공. 별도 읽기 호출에서 식과 값을 확인.
4. base_link 생성 성공.
5. 점별 개별 치수 구성에서 2회 과구속 오류.

```text
RuntimeError: 3 : VCS_SKETCH_OVER_CONSTRAINTS - 스케치 형상이 과도하게 구속됨
```

고정점 여부를 읽어 isFixed=false와 해당 점의 기하 구속 0개를 확인했다.
첫 기준점들의 x/y 치수를 설정하고 나머지 동일 좌표 관계는 수평·수직 정렬 구속으로 연결했다.
실패한 호출은 재조회에서 해당 호출 이전 상태로 확인됐으며, 삭제 호출 없이 구속 구성을 완료했다.
정확한 내부 솔버 실패 원인은 확인 불가. 최종 구속 상태는 별도 조회로 확인했다.

6. 고관절 레이아웃, FL 평면, 서기 및 웅크리기 스케치 구성 성공.
7. 최종 독립 읽기 호출 성공. 아래 측정값은 이 호출에서 반환됐다.

| 스케치 | 상퇴 (mm) | 하퇴 (mm) | 높이 (mm) | 무릎 안쪽각 (deg) | 상퇴 수직 기준각 (deg) | 완전 구속 |

- 각도는 Fusion MeasureManager.measureAngle로 실제 스케치 점의 worldGeometry를 읽어 측정했다.
- 무릎 각도는 hip → knee → foot의 중앙점 knee를 꼭짓점으로 측정했다.
- 상퇴 각도는 foot → hip → knee의 중앙점 hip을 꼭짓점으로 측정했다. foot은 hip 바로 아래다.
- cm→mm, rad→deg 변환은 Fusion UnitsManager.convert로 수행했다.
- AZN_A_hip_layout 완전 구속 true.

## 계산 참고

등길이 다리에서 무릎 안쪽각은 2 asin(h/(2L)), 상퇴 각도는 acos(h/(2L)).
L=200 mm, h=280 mm → 88.854008° / 45.572996°.
L=200 mm, h=200 mm → 60.000000° / 60.000000°.
위 식은 비교 근거이며, PASS의 각도 근거는 별도 MCP 측정값이다.
