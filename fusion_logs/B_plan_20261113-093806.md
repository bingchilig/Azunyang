## 공통 생성 방법

1. 승인 후 활성 문서, 매개변수, 기존 역할·원점·조인트·공유 그룹·Ground를 읽어 직전 기록과 비교한다. 같은 이름이 존재하면 중복 생성하지 않고 상태를 확인한다.
2. ACT_ref 컴포넌트 정의를 재사용하는 occurrence를 FR, RL, RR 순서로 각각 3개 생성한다. 모터 하나씩 생성·연결·재조회 후 다음으로 간다. 새 매개변수는 없다.
3. 역할은 {leg}_abad_motor, {leg}_hip_motor, {leg}_knee_motor로 기록한다. 실제 occurrence 이름과 역할 대응을 로그에 남긴다.
4. base_link 내부에 AZN_B_{leg}_{role}_target Joint Origin을 매개변수 식으로 생성한다. 루트의 임시 배치용 rigid joint 이름은 AZN_B_{leg}_{role}_mount이다. 이는 후속 링크 사이 Revolute Joint와 별개다.
5. source는 ACT_ref 내부 AZN_B_ACT_output_origin.createForAssemblyContext(대상 모터 occurrence), target은 해당 base_link origin의 assembly-context proxy를 사용한다. 입력 문맥과 생성 후 실제 occurrenceOne/Two를 별도로 읽는다.
6. 기존 AZN_B_ACT_internal_rigid 하나를 공유한다. 실제 native owner는 ACT_ref 내부의 가져온 하위 어셈블리 6010-8安装尺寸图-驱动盖可拆이다. ACT_ref 바로 아래 소유라고 잘못 보고하지 않는다. 모터별 그룹은 추가하지 않는다.
7. 기존 FL, 기준 ACT_ref:1의 원점·Ground·숨김, base_link Ground를 보존한다. 오른쪽은 위치의 Y 부호를 반전하고 실제 형상은 강체 회전으로 배치한다. 음수 스케일/반사 형상을 사용하지 않는다.

## 위치 식과 회전

앞 f=+1, 뒤 f=-1, 왼쪽 s=+1, 오른쪽 s=-1. f와 s는 배치 규칙의 부호이며 새 User Parameter가 아니다.

| 대상 | target X 식 | target Y 식 | target Z |
|---|---|---|---|
| abad | f*(abad_x + (act_mount_L - pin_H)/2) | s*abad_y | 0 mm |
| hip | f*hip_spacing/2 | s*(y_hipmot + act_mount_L) | 0 mm |
| knee | f*hip_spacing/2 | s*(y_kneemot + pin_H) | 0 mm |

실제 등록 식에는 f/s 변수 대신 해당 부호를 적용한다. source 원점은 기존 act_ref_output_x를 사용한다. 길이는 식 또는 단위를 명시한 문자열로 지정한다.

| 다리 | 출력면 중심 XYZ mm: abad / hip / knee | Z축 회전 deg: abad / hip / knee | 실제 모터 출력축 계획 |
|---|---|---|---|
| FR | (143.5,-45,0) / (190,-105.5,0) / (190,-142.5,0) | 0 / -90 / +90 | +X / -Y / +Y |
| RL | (-143.5,45,0) / (-190,105.5,0) / (-190,142.5,0) | 180 / +90 / -90 | -X / +Y / -Y |
| RR | (-143.5,-45,0) / (-190,-105.5,0) / (-190,-142.5,0) | 180 / -90 / +90 | -X / -Y / +Y |

목표 원점의 XYZ축은 FL과 같은 방향, offset=0 mm, isFlipped=false로 시작하고 전체 회전행렬을 다시 읽는다. 후방 외전 출력면은 -X를 향한다. 이 표의 실제 모터 축 방향은 §1.2 제어 관절 좌표계의 양의 회전축 정의를 변경하지 않는다. 같은 방향 무릎 결정도 유지한다.

- 모든 모터: 출력면 중심, 축 벡터, 회전행렬, 본체/커버 각각의 외곽, 내부 상대 변환, 조인트 연결 대상·식·건강 상태.
- 공유 정의: ACT_ref 컴포넌트 동일성, 전체 native Rigid Group 1개, 각 occurrence 문맥의 그룹 nativeObject 동일성 및 실제 본체·커버 동반 추종.
- 완료 시 계획 수량: 작업 모터 12개 + 숨긴 기준 1개; base_link 포함 루트 occurrence 14개, 배치 조인트 12개, User Parameters 44개. 수량은 실제 재조회로 판정한다.
- 위치·외곽 CAD 검증 허용오차 0.001 mm, 방향 0.001 deg. 제조 공차로 해석하지 않는다.

## 오른쪽 회전 배치의 커버·구멍 위상 실측

- FR·RR의 본체/커버를 각각 읽어 외곽과 비대칭 형상 기준점 방향을 기록한다. 커버 축방향 위치와 실제 회전 후 방향을 확인한다.
- 출력 6-M3, 앞/뒤 하우징 각 8-M3, 3-Ø4 핀 그룹을 실제 면에서 다시 찾아 지름·개수·PCD·중심좌표·축·위상을 기록한다. 소스의 측정값을 복사해 실측으로 표시하지 않는다.
- 위상 기준은 각 모터의 실제 출력축을 양의 법선으로 하고, 그 축에 수직인 global +Z를 0도로 삼아 오른손 방향으로 증가시킨다. 원본의 +Y 기준 위상과 비교할 때 같은 기준으로 변환한다.
- 소스 패턴을 계획 회전한 예측과 재조회한 중심/위상을 비교한다. 반복 대칭 패턴은 대응점과 주기를 기록해 동등한 위상을 구별한다. 구멍 위상은 엔코더 영점 측정으로 해석하지 않는다.
- 커버의 비대칭 형상 때문에 회전 배치가 기하학적 Y 반사와 동일하다고 가정하지 않는다. 배선·공구 접근에 영향을 주는 실제 차이는 기록하며, 판단에 필요한 정보가 없으면 HOLD로 남긴다.

## 전체 추종 및 간섭 시험 — 이번 승인 범위에 포함할 계획

1. y_kneemot: 139→135→139 mm.
2. y_hipmot: 65→66→65 mm.
3. abad_y: 45→46→45 mm.

각 변경과 복원 후 별도 읽기 호출로 12개 모터를 검사한다. 왼쪽은 식의 양의 Y 방향, 오른쪽은 음의 Y 방향으로 추종하는지, 관련 없는 모터가 정지하는지 확인한다. 기준 ACT_ref:1의 고정 및 본체/커버 내부 상대 자세도 확인한다. 시험 중 수동 재배치 함수는 사용하지 않는다. 마지막에 모든 원래 식과 기하 복원을 재조회한다.

간섭은 기준 occurrence를 제외하고 서로 다른 작업 모터 간 실제 바디를 검사한다. 본체·커버 2개씩이면 모터 66쌍 × 바디 4조합=264조합이며 실제 개수에 따라 검증한다. 검출된 쌍과 부피, 검사 실패를 기록한다. 현재 배치와 시험 상태의 결과를 §5의 전체 로봇 6자세 간섭 PASS로 확대하지 않는다.

## 중지·되돌림

- FAIL이면 해당 호출/검사에서 즉시 멈추고 오류 또는 불일치, 현재 파라미터 및 부분 생성 상태를 기록한다. 자동 Undo/삭제/복원은 하지 않고 먼저 보고한다.
- 되돌림 후보는 이번 단계에서 생성한 occurrence·배치 joint·target origin에 한정한다. 실제 실행 전 이름과 의존 순서를 보여주고 승인받는다. 기존 공유 원점·그룹·FL은 삭제 대상에서 제외한다.
- 추종 시험 실패 시 현재 매개변수 값을 유지한 채 보고하고 복원 승인을 받는다.
