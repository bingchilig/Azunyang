## 요약과 이전 해석 정정

준비 점검에서 Ø20.4를 보스 지름, 3-Ø4를 핀 구멍으로 읽은 것은 잘못이었다.
STEP의 원통 면, 표면 법선과 핀 끝 평면을 확인한 결과 3개 Ø4 형상은 돌출 핀이다.
Ø20.4는 그 핀들의 중심 PCD이며 Ø25는 출력측 6-M3의 PCD다.
출력부 원통 외경은 Ø34, 하우징 측 동심 단차는 Ø47이다.
기존 flange_BC=74는 하우징 체결 패턴에 해당한다. 출력축의 6-M3 토크 전달 반경에는 PCD25를 적용하도록 변경 제안한다.
STEP 전체 축방향 외곽은 핀과 드라이버 커버를 포함해 44 mm다. 출력 장착면부터 커버 끝까지는 40.5 mm다.
출력측 하우징의 8-M3는 STEP에서 깊이 4 mm이며 도면 표기는 5 mm다. 바닥 평면까지 확인했다.

## 측정 기준

- 가져온 모터 축은 전역 +X. 출력 6-M3의 입구 평면 X=29.5 mm를 s=0으로 둔다.
- s = STEP 전역 X - 29.5 mm. +s는 출력측 핀 끝 방향.
- 위상 0°는 +Y, 양의 회전은 +Y에서 +Z로 향하는 +X축 오른손 회전.
- 뒤쪽 패턴도 같은 좌표 기준을 사용한다.
- 위상은 STEP 저장 자세의 기하학적 위상이다. 엔코더 영점과의 관계는 확인 필요.
- 내부 cm를 UnitsManager.convert로 mm 변환해 기록했다.
- 모든 원통 면 606개를 순회했다. 주바디 581개, 드라이버 커버 25개.
- 동일 패턴을 축·지름·축방향 구간·반경 위치로 식별하고, 각 원통은 면 번호로 추적했다.
- 완전 대칭 패턴의 중심은 구멍 중심 좌표의 평균으로 계산하고, 각 중심의 반경 잔차로 검증했다.
- 나사산 형상은 모델링되어 있지 않다. Ø2.459 원통은 도면의 M3 지시와 대응하며 실제 유효 나사 깊이는 별도 확인 대상이다.

## MCP 오류와 복구

타임라인 추가 상태 조회에서 다음 오류가 발생했다.

```text
AttributeError: 'TimelineGroup' object has no attribute 'startIndex'
```

해당 호출은 읽기 전용이었다. API 문서의 TimelineGroup.count/item로 조회를 바꿔 성공했다.
TimelineGroup의 health=Unknown(5)는 문서상 그룹의 정상 반환 규칙이다.
그룹 내부의 실제 항목은 전부 Healthy(0)이며 오류·경고 메시지는 빈 문자열이다.
